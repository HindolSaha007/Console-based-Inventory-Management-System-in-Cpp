# Inventory Management System
A console based Inventory Management System developed in C++ using Object Oriented Programming and Binary File Handling.
The project allows vendors to manage products and customers to create accounts, login, browse products, categories, add products to cart, adjust quantity, and remove any product. The system also maintains records of Sales when the customer checks out the cart, and update the Inventory accordingly.

## Features
### Vendor Module
The vendor section allows users to:
1. Add new products.
2. View available products.
3. Check any product by name.
4. Check any product by category.
5. Restock a product.
6. Check Sales History.

### Customer Module
The customer section provides the following options:
1. Create a new customer account.
2. Login using a PIN.
3. Browse products using name.
4. Browse products using category.
5. View cart items.
6. Adjust cart items.
7. Delete any item from cart.
8. Confirm purchase using PIN verification.

## Technologies an Concepts used 
1. **Language:** C++
2. **Programming Concepts:**
  1. Classes and Objects.
  2. Inheritance.
  3. Member Functions.
  4. Conditional Statements.
  5. Loops.
  6. File Handling.
  7. Binary File operation.

4. **Interface:** Console based menu system.
